
# MotoParts | Build Planner

**Name:** Trix John D. Villaceran  
**Section:** IT2R5

## About the Project

MotoParts is a simple web application for motorcycle
enthusiasts. It allows users to add motorcycle parts
and organize information about their motorcycle builds.

## Features

- Add motorcycle parts
- Enter part names and brands
- Select a part category
- Organize motorcycle build information

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Use the application to manage motorcycle parts.
